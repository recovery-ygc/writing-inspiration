# writing-inspiration
写作灵感激发器 skill——给一个种子，列出书名、作者、位置与相关原文段，让作者自己去读、去感受不同氛围，打开视野。

## 四铁律

1. 不碰正文——不读、不围绕已写章节、不产一句可抄进正文的话
2. 出处真实——搜不到就明说"未确证"，绝不编造书名/段落/原文
3. 原文只放相关一段——约 300-400 字，只入私人灵感库
4. 不代写正文——正文纯手写是用户的底线

## 它做什么

- 意图解析：把种子拆成主词（职业/物件/场景）+ 辅词（气质）
- 跨书同类检索：同主题从不同书找类比，输出时同作者最多 2 条、同书 1 条；作者梯队约一半知名、一半小众有水平
- 文风强化（按需）：在你文风护栏内给技法方向，只给方向不给句子

## 配套

- 检索结果沉淀进本地文学索引库（JSON 给 AI 查 + Markdown 手账给作者翻），使用者拿到 skill 后由 AI 自动建库
- 库路径在使用者机器上按需调整
