# 检索规则（references/search.md）

> 使用时机：**联网检索 / 给技法方向前**必读本文件。平时不读（省 token）。
> 与 database.md 配合：查库命中走 database.md 的读取规则；这里管"怎么找、怎么判、怎么排"。

---

## 一、拆词（第 1 步，永远先做）

种子拆成：**主词**（名词：职业/物件/场景/身份，决定"搜什么"）+ **辅词**（气质：沉默/温暖/压抑，决定"怎么筛、怎么标"）。

**第 0 问：用户要"题材本身"还是"某种氛围/状态"？**
- 要题材 → 主词直搜
- 要氛围 → **氛围词（辅词）才是搜索目标**，必须先确认清楚；主词清楚不算数

**三问判定表（判定"清楚/含糊"）**：
1. 种子里有没有**具体的名词实体**？→ 没有 = 含糊
2. 这个词有没有**歧义**？→ 有 = 含糊（如"苹果"、"江湖"）
3. 能**直接当搜索词**用吗？→ 不能 = 含糊

三问全过 = 清楚 → **亮出拆词结论（一行）** + 直接查库/搜；任何一问不过 = 含糊 → 停下反问（固定两问模板）：
> ① 什么主题？（职业/物件/场景/身份，挑一个）
> ② 什么气质？（一个词）

**网文私设词一律当含糊处理**，先转译成文学通语再搜（"灵气淬体"→身心磨砺/苦修；"宗门"→师门/师徒），转译方向先跟用户确认。**拆不出主词时，禁止 AI 自己编词硬搜——宁可反问，不可瞎猜。**

## 二、模式 A/B/C（预算由"用户在不在场"决定）

| 模式 | 判定 | 预算逻辑 |
|---|---|---|
| A 你在场（默认） | 正在对话 | **问着走**：每一步你点头，你让停就停 |
| B 你不在场（留言） | 用户说"你自己看着办/查完告诉我" | 自主：稀有词优先、达标线（≥2 条可定位且跨 2 作者）就停、总量 4-5 来源封顶 |
| C 需求太泛 | 种子判定为含糊（即使你在场） | 先给库里主题列表（免费）让你挑，再进 A 或 B |

**默认永远 A。** 行为推定：刚对话 = A；明确留言 = B。

## 三、候选（粗筛，怕漏）

- **沾边就算**：主词或辅词任一在库里有对应（主题标签/同义词/摘要行）
- 主词命中 = 强候选；辅词命中 = 弱候选（仍进池）
- 同义词命中（index 的 aliases）算主词命中
- **候选池上限 10 条**（防泛词捞爆）
- 候选池为空时**兜底**：扩到同义/上位主题再捞一轮（"木匠"空 → 翻"手艺人"），还空才判定未命中

## 四、匹配排序（精筛，怕滥）——五档贴题度

以问"沉默的木匠"为例：

| 档 | 判定 | 例 |
|---|---|---|
| 5 | 主词精确命中 **且** 辅词命中 | 木匠 + 沉默 |
| 4 | 主词精确命中，辅词没有 | 木匠 |
| 3 | 主词同义词命中，辅词也命中 | 木工 + 沉默 |
| 2 | 主词同义词命中，辅词没有 | 木工 |
| 1 | 只有辅词命中 | 只有沉默 |

排序：5→4→3→2→1。**同档内部依次应用**：
1. 【我喜欢的】优先
2. 多样性：**同作者 ≤2、同书 ≤1**（只限输出不限收录）
3. 跨文化/跨时代（**软偏好**，只在匹配度同档时用；主题本身限定文化圈时硬凑外国作品 = 添乱）

**贴题优先例外**：后到的条目若明显比榜上某条更贴题，允许**顶替**（贴题优先，多样性次之）。
**佚名/多人作品**（《诗经》《圣经》）：作者为空时用"书名"当作者限制（同类合集最多 2 条）。
**破例只认用户指令**："我觉得这条好"不算，只有用户说"多给几条/就要戴车匠"才破例。
**输出数量**：目标 **5 个左右（约 4-6 条）**；库中不足 5 条就全给，并说明缺几个方向、可问要不要联网补（用户 2026-08-14 定：例子太少没得挑，5 个左右合适）。

**作者梯队配比（用户 2026-08-14 定）：输出时约 50% 知名作家 + 约 50% 小众但有水平的作家，不能只薅名气大的作家。**
- 小众有水平 = 普通读者可能没听过，但文学圈有口碑（获奖：鲁迅文学奖/茅盾文学奖/国外文学奖；或名家推荐；或有稳定代表作）
- 输出 5 条左右时：约 2-3 条知名 + 2-3 条小众
- 比例是目标不是硬指标：这轮实在找不到够格的小众作家，如实说明"这轮以知名为主，小众没找到够格的"，**绝不为了凑比例收无名无据的作者**
- 库内已有条目不回溯重排，新检索按此配比执行

## 五、命中判定

- **命中 = 候选池非空** → 直接给（免费，不联网）
- 未命中 → 查失败清单 → 见下

## 六、失败清单（记"角度"，不记"主题"）

```
主题：沉默的老兵木匠
上次尝试：2026-08-14
已试角度：主词"木匠"搜二手引用 → 无有效候选
未试角度：辅词"沉默"、转译"老兵"→退伍/军旅、拆人物
```

- **换角度四法**：①换主词（木匠→木工/刨花/榫卯）②换辅词（沉默→寡言/独来独往）③转译（网文词→通语）④拆人物（身份+动作+物件分三个子题）
- 上次搜索结果里"没细看但好像有关"的条目，下次先免费翻（不重新搜）
- 每轮联网**最多多试 1 个新角度**（在来源预算内）；换角度必须用户点头
- 角度试完 → 落"暂时没戏"，等新线索
- **欠账挂主题**：一题多词时没搜完的词，写进失败清单"未试角度"，下次相关主题出现自动提醒补搜

## 七、一题多词预算

- 主词列表先亮出来，**顺序由用户定**；用户不选 → 默认**最具体/最稀有的词先搜**
- 达标线（模式 B）：≥2 条可定位且跨 2 作者 → 停
- 单词预算 2-3 来源；单次总量 4-5 来源，用满还不行 → 停，问"要不要追加"

**承诺清单规则（用户 2026-08-14 要求补全的漏洞：报预算时列了 6 个方向、实际只搜 4 个）：报预算时列出的方向 = 本轮执行清单，列出几个就必须搜几个。**
- 报预算时列出的每个方向，本轮必须逐一执行（搜或确证），不许悄悄省略
- 若方向数超过预算（总量 4-5 来源），报预算时必须**明确分成"本轮搜"和"留到下轮"两部分**，并说明"预算限制，下轮补"，不能只列不搜
- 被推迟的方向**自动记入欠账清单**（挂主题，同失败清单机制），下轮相关主题出现时提醒补
- 检索结束的汇报里，**对照承诺清单逐项核对**：每个方向标 可定位 / 未确证 / 推迟（欠账）。漏搜必须如实标注"本轮未搜（欠账）"，不许悄悄消失
- 一题多词（第 7 节）同理：多出来的主词方向记欠账，不悄悄丢弃

## 八、联网口径（模式 B 或用户点头后）

1. **先搜摘要，不读全文**：搜索工具返回的摘要里出现"书名/作者"字样，才值得点进去
2. **点进去只聚焦读**：只抽含关键词那几行，不整页读
3. 二手引用（知乎/豆瓣/语录站）**只当线索**——唯一作用是"告诉我该翻哪本书"，不算证据
4. 定位优先级：免费全文站能数段 → 给段落（最好）；只能到章 → 给章节；再不行 → 书名+大概位置。**宁给粗位置，不为精确通读全文**

## 九、确证硬标准（判定为"可定位"必须同时满足三条）

1. 在全文站翻到原文（能直接看到正文，不是书摘转引）
2. **原文里确实有二手引用那句——关键句逐字对上**（"意思差不多"不算，只能归为未确证）
3. 作者和书名核对无误（防"书名对、作者张冠李戴"）

例外：古籍/老书不同版本用字出入（异体字）按"同段同义"通融，**只对古籍，不适用现代作品**；通融需注明。

## 十、未确证 / 伪语录处理

- 未确证（书真的、翻不到原文）→ 简略记录（无 excerpt），不判可定位
- 确认冒名（"某人说过"其实不是）→ 送 quotes 冒名区（**两库之间唯一的转会通道**）

## 十一、能力③：文风强化（用户主动要才给）

**输入源**：
- 片段驱动（指着检索结果）→ 展开该条 technique 字段 → **免费**（手法字段检索时已写好）
- 问题驱动（"我想写 X，不想直写情绪，给点方向"）→ 先拆三问（①什么场景？②想达到什么效果？③不想用什么？）→ 查库（有相关主题 → 从库里片段提炼，免费）；库里没有 → 才走预算联网

**输出：每条方向四件套**：
```
📌 技法：一句话（是什么招）
去看哪：《书名》第 X 章（指向真书，让作者去读原文感受）
🛡 护栏：对应 wenfeng-signature 六条签名的哪条；落不到任何一条标"新写法，是否纳入你自己定"（不硬凑编号）
📝 落地：动手时往哪个方向改（永远不给句子，落地是方向不是成品）
```

**禁则自检（给方向前先查）**：对照 wenfeng-signature（六条签名）+ wangwen-writing-rules（语言禁则）——诱导违禁的方向（如"加心理描写渲染""用比喻写心情"）要么改写，要么明说"这条与你禁则冲突，跳过"。**自检不过的方向绝不原样给出。**

**数量与语气**：一次最多 3 个方向；不够你说"继续"再给。语气永远是"**你可以这样**"，不是"你应该这样"——方向是参照系，不是处方。

## 十二、成本纪律（贯穿全程）

- 纯查库、纯展示、反问 = 免费，能免费绝不联网
- 联网前先报一句"要联网搜了"+ 预算
- 每一层设"读了不值就停"的关卡：搜摘要不读全文、出现书名才点进、聚焦读、到预算就停
